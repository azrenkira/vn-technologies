# VN Technologies

Corporate website for VN Technologies, a Masbate-based software development and
IT consultancy company.

## Current focus

- Custom software development
- Web and mobile applications
- IT consultancy and digital transformation
- Data, reporting, and systems integration
- Managed application support
- MCEMPC Loan Management System (in development)

## Local preview

Open `index.html` directly, or serve the directory with any static web server.

## GitHub Pages

The included workflow publishes the site to GitHub Pages whenever changes are
pushed to the `main` branch.
